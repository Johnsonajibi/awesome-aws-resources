### Reference Architectures
- [AWS Solutions Library](https://aws.amazon.com/solutions/) - Pre-built solutions
- [AWS Reference Architecture Diagrams](https://aws.amazon.com/architecture/reference-architecture-diagrams/) - Visual diagrams
- [Serverless Land](https://serverlessland.com/) - Serverless patterns
- [AWS Prescriptive Guidance](https://aws.amazon.com/prescriptive-guidance/) - Migration & modernization

### Design Patterns by Use Case

**Web Applications:**
- Three-tier web application architecture
- Serverless web application (S3 + CloudFront + Lambda)
- Containerized microservices (ECS/EKS)
- WordPress on AWS (Elastic Beanstalk)

**Data & Analytics:**
- Data lake architecture (S3 + Glue + Athena)
- Real-time analytics pipeline (Kinesis + Lambda)
- ETL workflows (Glue + Step Functions)
- Business intelligence (QuickSight)

**Machine Learning:**
- ML inference architecture (SageMaker)
- Batch prediction pipelines
- Real-time ML serving
- MLOps on AWS

**Security:**
- Multi-account strategy (AWS Organizations)
- Security automation (Config + Lambda)
- Compliance monitoring (Security Hub)
- Identity federation (SSO)
